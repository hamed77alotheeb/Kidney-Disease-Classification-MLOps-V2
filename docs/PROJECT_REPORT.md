## 1. الملخص التنفيذي

يوفر المشروع تطبيقًا لتصنيف صور الكلى إلى أربع فئات: `Cyst` و`Normal` و`Stone` و`Tumor`. يتضمن التطبيق نموذجًا أساسيًا وتجربة ضبط دقيق، ووحدة تنبؤ، وواجهة ويب عربية مبنية باستخدام Flask.نجحت اختبارات محلية لفتح الواجهة ورفع صورة من مجموعة التحقق. هذه النتيجة تثبت نجاح مسار التشغيل الذي تم اختباره،.

## 2. أهداف المشروع

1. تنظيم عملية تصنيف الصور ضمن بنية قابلة للصيانة.
2. فصل إعدادات المشروع عن الكود.
3. توفير واجهة ويب لتجربة التنبؤ بصورة محلية.
4. توثيق المكتبات والنتائج وطريقة التشغيل.
5. حماية البيانات والأوزان من الرفع غير المقصود.

## 8. مقاييس تقرير التحقق

المصدر: `reports/metrics/validation_error_audit.json`

| المقياس | القيمة |
|---|---:|
| Validation Accuracy | 90.72% |
| Macro F1-Score | 89.26% |

### المقاييس حسب الفئة

| الفئة | Precision | Recall | F1-Score |
|---|---:|---:|---:|
| **Cyst** | 91.95% | 97.56% | 94.67% |
| **Normal** | 94.32% | 88.53% | 91.33% |
| **Stone** | 75.21% | 89.22% | 81.61% |
| **Tumor** | 92.50% | 86.55% | 89.43% |

**Precision:** نسبة التنبؤات الصحيحة ضمن جميع التنبؤات الإيجابية للفئة.

**Recall:** نسبة الحالات الحقيقية من الفئة التي استطاع النموذج تحديدها.

**F1-Score:** متوسط توافقي بين Precision وRecall.

**Macro F1:** متوسط متساوي الأوزان لقيم F1 عبر الفئات.

**Weighted F1:** متوسط F1 موزون بعدد الأمثلة في كل فئة.

### تفسير الاختلاف بين التقارير

تختلف دقة التحقق في ملخص الضبط الدقيق عن دقة التحقق في تقرير التدقيق. يجب التحقق من ملف الأوزان المستخدم عند إنشاء كل تقرير قبل نشر نتيجة نهائية أو مقارنة مباشرة.

## 9. آلية عمل النظام

1. استقبال الصورة من واجهة Flask.
2. التحقق من الملف وتجهيزه للنموذج.
3. استدعاء وحدة التنبؤ.
4. استخراج مخرجات الفئات الأربع.
5. عرض الفئة ودرجات النموذج على الواجهة.

الإعدادات موجودة في `config/config.yaml`، وأوامر التشغيل موجودة في `main.py`.

## 10. تثبيت المشروع وتشغيله

أنشئ بيئة مستقلة على Windows:

```powershell
py -3.8 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

تأكد من توفير ملفات الأوزان المطلوبة في مجلد `models/`، ثم شغّل الواجهة:

```powershell
python main.py web
```

افتح العنوان:

`http://127.0.0.1:5000`

الأوامر الأخرى:

```powershell
python main.py --help
python main.py train-baseline
python main.py fine-tune
python main.py evaluate-validation
```

التدريب والتقييم عمليتان منفصلتان عن تشغيل الواجهة.
